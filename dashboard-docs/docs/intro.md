# Dashboard user guide

How to use the MetaForge dashboard: your engineering workspace for projects, design runs, approvals, 3D models, parts, files, knowledge, and compliance.

## What this guide covers

- **Getting around** — navigation, project picker, appearance, and connection status. Start here.
- **Projects** — organise your work.
- **Runs** — start a design run and follow it through review.
- **Approvals** — review and decide what is waiting on you.
- **Digital twin** — explore your design in 3D and graphs.
- **BOM + Files** — parts to buy and source files.
- **Knowledge + Compliance** — what the system knows and what evidence is still missing.
- **Sessions + Settings** — what agents did, and how to connect.
- **Current limitations** — pages that are still stubs and behaviours to expect.

Tip: the dashboard opens on **Projects**. If you ever get lost, click **Projects** in the left rail to return home. Unknown addresses show a *Page not found* screen.
