# Current limitations

Things worth knowing so you are not surprised.

## Preview pages

- **Source details** (`Knowledge › open a source`): some sources currently show a *coming soon* placeholder. The rest of the Knowledge table works normally.

## Behaviours to expect

- **Project picker matters:** the twin, parts list, files, knowledge, and compliance pages all show data for the project selected in the top bar. If a page looks unexpectedly empty, check the picker first.
- **Sample workspace resets:** the **Sample** example in the top bar is for learning — anything you do there disappears on refresh.
- **Connection vs. empty:** a dash instead of a number, or a *Connect your engineering gateway* message, means the dashboard cannot reach your workspace server — your data is not deleted. Choose **Retry**, or go to Settings and check the address.
- **Simulation is a sanity check:** the twin's Sim view shows gravity and joint movement for a quick look, not a full engineering analysis.
