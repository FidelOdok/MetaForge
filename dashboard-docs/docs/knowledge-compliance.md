# Knowledge + Compliance

Knowledge shows what reference material the system has stored; Compliance shows what regulatory evidence is still missing. Both follow the project picker in the top bar.

## Knowledge — stored sources

**What you can do here:**

- **Browse** the sources table: file path, type label, number of extracts, when it was added, vendor, and part number. Select any column header to sort; select a row to open that source.
- **Filter by type** with the chips (*all, design decisions, components, failures, constraints, sessions, other*).
- **Search** with the top-right box: typing switches the table to matching extracts (type label, source, and a short preview). Select a match to open its source. Clearing the box returns to the full table.
- **Add more:** if the table is empty (*No sources ingested yet*), ask your administrator to ingest files — new sources appear here with their extract counts after reloading.

## Source details

Opening a source shows its full details. Note: this page is still a preview — some sources show a *coming soon* placeholder. Your administrator can provide the full view on request.

## Compliance

**How to close your compliance gaps:**

1. **Pick a project** in the top bar first — with none selected the page asks you to choose one.
2. **Choose your markets** with the market buttons (UK, CE, FCC, and others; UK + CE are selected by default). The checklist rebuilds for each market set; with nothing selected it asks you to pick at least one.
3. **Read coverage** in the summary cards: how many requirements already have evidence, out of the total, plus a progress bar per market.
4. **Close gaps** in **Missing Evidence** (left): select a missing item to open a short form, enter an **evidence title**, pick a type (test report, declaration, certificate, technical file, or risk assessment), optionally add a description, then **Link evidence**. It leaves the missing list on success and stays saved after reloading. Items that already have evidence show a tick and are listed read-only in the full **Checklist** (right, scrollable).
