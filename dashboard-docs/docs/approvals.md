# Approvals

One inbox for everything waiting on a human decision. Work from top to bottom: unblock live work first, then decide on design changes.

## 1. Run approval gates

These are design runs paused between phases, waiting for you. Each entry shows the run's goal and why it needs review — select **Inspect and decide** to open the run and approve or reject it there. Approving lets the run continue; rejecting stops it. This is the only list that resumes automated work.

## 2. Pending tool calls

Sometimes an agent pauses mid-task to ask permission before doing something sensitive (for example saving geometry or changing project data). Each entry shows what it wants to do and when it asked. Choose **Approve** to let that exact action go ahead, or **Reject** to cancel it. Clear these first, because the agent is actively waiting on you.

## 3. Change proposals

These are suggested changes to your design. Each card shows:

- what is being proposed, which agent suggested it, and when,
- which items it affects,
- a **change preview** showing what would be added (green) and removed (red) — read this before deciding,
- **Approve / Reject** buttons (only for items still waiting),
- who decided and when, once resolved.

Summary cards at the top count **Pending / Approved / Rejected** proposals so you can see the mix at a glance. Approving applies the change to your design.

When there is nothing waiting, each section shows a friendly empty message (*No runs awaiting approval*, *No tool calls awaiting approval*, *No pending proposals*) instead of loading forever.
